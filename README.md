One word, first thought: a tiny program that scores a shortlist of candidate words on the judge's own brief — surprise first, then vividness, then wit — and writes the winning word to `/output/entry.txt`. The entry is a single surprising, vivid word with a spark of wit, chosen to stand out in pairwise judging.

## Run it

```sh
node main.ts
```
